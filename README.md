# Final Year Project: Topological Data Analysis (TDA) Approach on Flood Detection in Alor Setar, Kedah

## 📌 Project Overview & Problem
Analyzing highly volatile, non-linear seasonal climate datasets to forecast disruptive regional environmental anomalies is incredibly complex. Standard statistical models often miss the underlying geometric shape and hidden patterns within chaotic weather anomalies.

This Final Year Project (FYP) applies Advanced Mathematics and **Topological Data Analysis (TDA)** to structure and extract topological features from historical climate data in Alor Setar, Kedah, serving as an early-warning risk mechanism.

## 🛠️ Methodology & Technical Stack
* **Core Stack:** R Programming (`TDA` package, `GUDHI` / `TDAstats`), RStudio
* **Analytical Methods:** Topological Data Analysis (TDA), Persistent Homology, Statistical Modeling, and Time-Series Forecasting.

## 🎯 Key Findings & Analytical Impact
* **Persistent Homology Modeling:** Engineered a structured visualization matrix utilizing **Barcode Graphs** and **Persistent Diagrams (PD)** to distinctly isolate flooding months (e.g., October) from baseline non-flooding months (e.g., February).
* **Advanced Anomaly Detection:** Successfully captured hidden, high-dimensional data shapes and persistent topological "holes" within weather data that represent structural environmental shifts.
* **Operational Risk Mitigation:** Proved that advanced quantitative abstractions and mathematical topological structures can be effectively translated into predictive real-world business and environmental solutions.
